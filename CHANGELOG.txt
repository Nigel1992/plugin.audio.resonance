Resonance Version 1

v1.0.2 - 2026-09-23

- Added artist context menus from track, album and artist rows.
- Added artist top songs, albums, singles, appears-on and combined artist overview pages.
- Artist top songs falls back to a Spotify search when the top-tracks endpoint is unavailable.
- Removed related artists after live testing confirmed Spotify returns HTTP 403 for this app.
- Changing the unreadable-playlist toggle now clears both catalogue data and addon runtime caches before refreshing the current menu.
- Added regression coverage for artist browsing endpoints.

v1.0.1 - 2026-09-23

- Hotfix: preserve the Spotify browser-login refresh token when Spotify refresh responses omit a replacement token.
- Prevents the catalogue sign-in from requiring the zip1/browser login again after access-token expiry and addon restarts.
- Added the option to hide playlists Resonance cannot read.
- Changing the unreadable-playlist toggle clears the catalogue cache, notifies the user and refreshes the current menu.
- Added regression coverage for refresh responses that only return a new access token.

v1.0.0 - 2026-09-22

- Initial Version 1 release of Resonance for Kodi.
- Search, playlists, albums, artists, links and track metadata use the browser PKCE token.
- Playback remains handled by Device Connect and the bundled Spotty/librespot helpers.
- Added browser PKCE sign-in through the hosted Resonance callback relay.
- Added Device Connect pairing for playback.
- Added persistent catalogue caching and shared Spotify API cooldown handling.
- Added loopback audio streaming into Kodi.
- Uses the regular Spotify Web API catalogue only.
- Supported target is LibreELEC on Raspberry Pi ARM/AArch64; Android ARM is experimental.
- Windows, macOS and Linux x86/x64 are not supported by this release.
- Verified with the full unit test suite.
